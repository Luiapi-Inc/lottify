# Lottify Member — iOS-inspired interactive mockup

Alternative visual concept for the approved Lottify v1 Member UX. This version keeps the same information architecture and business flows as `member-frontend-v1` while presenting them with an iOS-inspired mobile-first visual system.

## Open

- Home: `index.html`
- Core betting flow: `buy.html` → `bet.html` → `quote.html` → `receipt.html`
- Wallet: `wallet.html` → `deposit.html` / `withdraw.html`
- Account: `account.html` → `security.html`
- Onboarding: `register.html` → `otp.html` → `terms.html` → `profile.html` → `eligibility.html` → `index.html`

## Visual direction

- system-style typography stack and large titles
- translucent navigation and surfaces with blur
- grouped content cards and inset controls
- iOS-style segmented controls, semantic system colors and rounded actions
- floating mobile tab bar with vector icons
- responsive desktop/iPad sidebar and iPhone layout

This is a static clickable mockup; financial actions are simulated UI only.
