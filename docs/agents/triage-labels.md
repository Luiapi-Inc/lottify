# Triage Labels

The engineering skills use five canonical triage roles. This file maps those roles to the label strings used in this repo's GitHub issue tracker.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an implementation agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or intervention |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to one of these canonical roles, use the corresponding GitHub label from this table.
