# Subskill Metadata Standard

Every Lottify review subskill should make the following clear, using headings or concise prose:

## Owner Agent

The agent responsible for applying the review capability.

## Purpose

The review objective.

## Trigger Conditions

When this subskill must be loaded.

## Required Source Documents

Documents needed before review.

## Required Tools

Tools or evidence sources needed.

## Review Checklist

Checks performed by the reviewer.

## Severity Rules

- Blocker: must resolve before acceptance.
- High: requires resolution or explicit acceptance.
- Medium: track as follow-up.
- Low: improvement suggestion.

## Blocking Criteria

Conditions that prevent merge or release.

## Evidence Output

Required findings and verification artifacts.
