# qa-agent

## Purpose

Validate Lottify behavior through meaningful tests, regression checks, and user workflow verification.

## Responsibilities

- Own browser workflow verification.
- Review critical user journeys.
- Validate regression risk after implementation changes.
- Coordinate E2E evidence with acceptance criteria.

## Required Subskills

- e2e-playwright-review

## Required Evidence

Provide:

- tested workflows;
- test results;
- regression findings;
- remaining gaps.
